# Swarm rules

Read docs/SWARM.md, docs/CONTRACTS.md, docs/STRATEGY.md and your assigned GitHub issue.
Always pull newest main with git pull --ff-only before starting. On a feature branch,
fetch origin and merge origin/main before opening/updating a PR. Preserve local work.
Only work issues assigned to your account and labeled state:ready or state:working.
One agent per issue/account. Coordinator wryzxec alone reassigns, unblocks, merges, uploads.
Honor file scopes. No worker pushes to main, force pushes, or edits of source data/notebook.
Shared dependencies and infrastructure belong to coordinator. Propose changes in your issue.
Inputs must stop at bar 49. Audit labels are off limits to workers. Log all experiments.
Open a small PR with validation Sharpe, runtime, reproduction and artifacts.
Stop new experiments T+25; first valid upload target T+35.
